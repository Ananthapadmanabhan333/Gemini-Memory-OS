## 🌌 Core Vision & Architecture

**Gemini Memory OS** functions as a continuous, long-term cognitive operating system layer. While standard LLM systems operate on ephemeral conversational sessions, this architecture empowers AI agents to establish persistent user identities, recall multimodal histories, map semantic networks, track natural temporal dimensions, and dynamically improve self-awareness over time.

## 🛠️ Key Highlights

1. **Multimodal Memory Engine:** Consolidates episodic text, voice chat audio waveforms, active screenshot OCR scans, and workspace preferences into a single searchable hybrid database.
2. **Adaptive Decay & Reinforcement:** Mathematically decays memory importance over time ($S_{new} = S_{old} \times e^{-\lambda t}$) and boosts scores based on recurrent query hits.
3. **Temporal Reasoning Engine:** Parses conversational time bounds like *"last week"* or *"yesterday"* and filters chronological timelines.
4. **LangGraph Agentic Cockpit:** Coordinates specialized cognitive subagents (`Planner`, `Context`, `Task`, `Research`, `Reflection`) with complete execution traces.
5. **Zero-Dependency Fallback:** Connects to PostgreSQL, Neo4j, and Qdrant in cloud-scale deployments, falling back to fully functional SQLite, NetworkX, and in-memory NumPy cosine similarity layers locally.

## 🧠 Cognitive Framework & Algorithms

### 1. Mathematical Memory Decay & Reinforcement
To simulate human cognitive retention, the platform processes memory items with exponential decay:

$$S_{new} = S_{old} \times e^{-\lambda t}$$

Where:
- $S_{new}$ is the adjusted current relevance score of the memory.
- $S_{old}$ is the initial importance score (1.0 to 10.0) generated by the system.
- $\lambda$ is the user's specific cognitive decay rate (e.g. `0.05` for standard retention).
- $t$ is the time elapsed in days since the memory was captured.

**Recurrence Reinforcement:** When a memory is successfully retrieved and used as context in conversations, its `reinforcement_count` increments. The system applies a reinforcement boost factor:
$$Boost = 1.0 + (Count \times 0.15)$$

**Emotional Valence:** Positive/Negative emotional weights apply additional relevance boosts to high-importance events:
$$Score_{final} = (S_{new} \times Similarity \times Boost) + (|Emotional Weight| \times 0.1)$$

### 2. Multi-Agent LangGraph Cognitive Loop
The system runs on a compiled StateGraph pipeline featuring five specialized agents:
- **Planner Agent:** Deconstructs query structures into structured execution plans.
- **Context Agent:** Coordinates the hybrid retrieval suite, fetching relative vectors and tracing connections.
- **Task Agent:** Predicts active actions, scheduling proactive agent reminders.
- **Research Agent:** Performs mock-synthesis crawls to extract domain-specific knowledge.
- **Reflection Agent:** Acts as the final safety layer, refining emotional weighting and generating responses.

## 🚀 Local Quick Start

A fully automated batch deployment control is available for Windows systems.

### 1. Automated Setup (Recommended)
1. Double-click `scripts/setup_env.bat` or run it from a PowerShell terminal.
2. The setup script will automatically:
   - Configure sandbox local environment variables.
   - Establish a python virtual environment and install dependencies.
   - Run the compiled unit test suites validating vectors, graphs, and temporal boundaries.
   - Launch the FastAPI server (Port `8000`) and Next.js UI developer cockpit (Port `3000`) in separate command panes.

### 2. Manual Setup
To configure steps manually:

**Backend:**
```bash
cd backend
python -m venv venv
venv\Scripts\activate  # On macOS/Linux: source venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

**Frontend:**
```bash
cd frontend
npm install
npm run dev
```

Open your browser to:
- **FastAPI Documentation:** [http://localhost:8000/docs](http://localhost:8000/docs)
- **Memory OS Cockpit HUD:** [http://localhost:3000](http://localhost:3000)

## 📡 API Reference & Streaming Channels

### 1. REST Endpoints
* `POST /api/v1/auth/signup` - Register new user account.
* `POST /api/v1/auth/login` - Obtain authentication token.
* `POST /api/v1/memory/` - Create a new multimodal memory.
* `GET /api/v1/memory/search?query=...` - Execute hybrid vector-graph contextual recall.
* `GET /api/v1/memory/timeline?query=...` - Chronological timeline filtered by relative dates.
* `GET /api/v1/memory/graph` - Obtain D3 node-link data representation.
* `POST /api/v1/memory/compress` - Manually trigger memory consolidation.
* `POST /api/v1/agents/run` - Trigger LangGraph loop query.

### 2. WebSocket Channel (`/api/v1/ws/stream`)
Supports streaming communication:
* Send `{"type": "voice_chunk"}` to trigger live audio frequency waveform visualizations.
* Send `{"type": "screenshot_stream", "image": "base64_data", "app_context": "VS Code"}` to trigger multi-modal visual OCR layout analysis and record episodic memories.
* Send `{"type": "chat_message", "content": "..."}` to stream back conversational response tokens character-by-character.
